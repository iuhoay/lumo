How it works

Choose the entry point that fits.

Lumo is useful as a standalone app first, with PopClip as an optional fast path for selected text.

01

Open Lumo

Use the menu bar, assign a global shortcut, or open an empty window when you want to work from the clipboard.

02

Send text in

Paste or type text directly, press Tab to use the clipboard, grab on-screen text with OCR, or tap 翻译, 润色, or 总结 from PopClip.

03

Read the streamed result

The app opens with the answer streaming in — saved to history, ready to copy or hear aloud.

Get Lumo

Two steps and you're set.

Install the app first. PopClip is optional; Sparkle handles updates after the first launch.

Step 1 — The app

Install Lumo.app

Download Lumo.zip, unzip it, and move Lumo.app to /Applications. Clear the quarantine flag once:

xattr -dr com.apple.quarantine /Applications/Lumo.app

It launches into the menu bar — look up top, not in the Dock. From then on Sparkle keeps it current.

Step 2 — Settings

Configure your provider

Open Lumo from the menu bar and set your provider, model, API key, translation languages, and optional global shortcut in Settings.

Use OpenAI, Claude, DeepSeek, local Ollama, another OpenAI-compatible endpoint, or Apple's on-device model (no API key).

Optional integration

Add PopClip for selected text

If you use PopClip, install Lumo.popclipext to send selected text to Lumo in one click. The extension is only a trigger; Lumo.app still handles providers, streaming, history, and speech.
