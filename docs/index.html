How it works

From selection to result in seconds.

Lumo is two coupled parts: a thin PopClip trigger and a native app that does the thinking.

01

Select any text

Highlight a sentence, paragraph, or page in any app — Lumo works wherever PopClip does.

02

Click in the PopClip bar

Tap 翻译, 润色, or 总结. The text hands off to the app over a lumo:// URL.

03

Read the streamed result

The app opens with the answer streaming in — saved to history, ready to copy or hear aloud.

Get Lumo

Two steps and you're set.

The app is ad-hoc signed, so there's one quarantine command the first time — after that it updates itself.

Step 1 — The app

Install Lumo.app

Download the zip, unzip it, and move Lumo.app to /Applications. Clear the quarantine flag once:

xattr -dr com.apple.quarantine /Applications/Lumo.app

It launches into the menu bar — look up top, not in the Dock. From then on Sparkle keeps it current.

Step 2 — The trigger

Add the PopClip extension

Grab Lumo.popclipext from the repo, double-click to install it into PopClip, and enable it.

Open the app once from its menu-bar item and set your provider, model, and API key in Settings. That's it — select text and go.
